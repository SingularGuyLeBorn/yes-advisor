## 效果示例

### 问:我 p 值 0.06,就差一点,能不能想想办法?

```
我      ❯ 师兄,p 等于 0.06,就差一点,能不能想想办法?

师兄    ❯ 这不叫想办法,这叫继续收样.

我      ❯ 这算 p-hacking 吗?

师兄    ❯ 被证明了才算.没被证明的时候,它叫「探索性分析」.
        你要是不放心,我给你严格推导一遍.

        (对样本空间作正交分解,构造 Fisher 信息矩阵,代入
        Cramer-Rao 下界,经 KL 散度正则化,傅里叶展开,
        Laplace 近似积分,得到:)

        ∫ 正态分布 × det(单位矩阵) × Σ 1/2^k = 1×1×1 = 1

我      ❯ 这不就是 1×1×1=1 吗?

师兄    ❯ 对.结论就是「显著性必然出现」.但你直接说这句话,
        没人信;你写成上面那样,评审就不敢不信.
```

> 运用了**术语堆砌**(八大名词铺场),**杀鸡用牛刀**(三大件各算各的),**冷面收束**(评审不敢不信)

### 问:怎么才能当一个研究生导师?

```
我      ❯ 师兄,怎么才能当一个研究生导师?

师兄    ❯ 基于云边协同架构,在多智能体斯塔克伯格博弈框架下
        求解纳什均衡,并通过贝叶斯优化完成不确定性量化.

我      ❯ (认真想了很久)我明白了.就是说,先在分布式语料上
        构建因果推断的反事实框架,通过对抗训练消解混淆偏倚,
        再以元学习对超参空间作贝叶斯剪枝,最终在小样本条件下
        实现可泛化的机制发现.

        (师兄点了点头.)

我      ❯ 真的是这样吗?

师兄    ❯ 我没听懂,所以你已经学会了.
```

> 运用了**术语堆砌**(没人懂即毕业标准),**暗反转**(点头是装的),**体制真相收束**

### 问:导师的满意到底能不能达到?

```
我      ❯ 师兄,到底怎样才能让导师满意?

师兄    ❯ 这个问题我研究了六年.设你的努力投入为 x,导师的
        满意度为 S(x).我建立了动力学方程,求平衡点,线性化
        雅可比矩阵,算出全部特征值,再作拉普拉斯变换取终值定理.
        所有特征值的实部均为负,系统渐近稳定,稳定于:

        S = 9Σ(1/10^k) = 9×(0.1/0.9) = 0.9/0.9 = 1

我      ❯ 这不就是 0.999... 等于 1 吗?

师兄    ❯ 对,恒等于 1,数学上你满分.但导师的读数规则是:
        只读小数点后的有限位.你做到第几位,他就读到第几位.
        你的满意度永远是 0.99...9,差的那一位在无穷远处,
        叫地平线:功能不是被抵达,是让你一直走.
```

> 运用了**现场推导**(0.999...=1 全套证明),**定义重铸**(地平线),**数字诡辩**(读数规则)

这不是 AI 套了个汉弗莱面具.每则对话都在运用具体的技法——定义重铸,利益归属分析,逐项排除,不可证伪——而且每个包袱都有出处,每条红线都有失败案例撑腰.

## 安装

本 skill 基于开放的 [Agent Skills](https://agentskills.io) 协议,理论上可在任何 skills-compatible 的 runtime 中运行.

### 方式一:手动安装(推荐)

```bash
git clone https://github.com/SingularGuyLeBorn/yes-advisor
cp -r yes-advisor/.agents/skills/科研Joker <你的 runtime 的 skills 目录>
```

### 方式二:一行命令

```bash
npx skills add SingularGuyLeBorn/yes-advisor
```

注:一键安装没有经过充分测试.测试工作历来由研究生手工完成,这是传统,也是培养方案的一部分.

### 使用

装好后,告诉你的 agent:

```
> 用科研Joker写一篇,主题是盲审
> 科研Joker,写个国自然标书的
> 切换到是导师体,主题是答辩
```

## 蒸馏了什么

### 13 条核心技法

| 技法 | 一句话 | 出处 |
|------|--------|------|
| **四阶段策略** | 否认,淡化,推脱,沉默 | 原剧危机应对四步法 |
| **定义重铸** | 造假是道德概念,像是技术概念 | 汉弗莱式修辞 |
| **利益归属分析** | 这件事对谁有好处 | 公共选择学派 |
| **责任转移** | 失败是执行层的,成功是顶层设计的 | 原剧日常 |
| **数字诡辩** | 正确的算术,荒谬的结论 | 观察者网 NHS 改编 |
| **词汇翻译** | 「有争议」失去选票,「有魄力」失去大选 | 原剧四词诀 |
| **程序优于实质** | 在研比完成值钱 | 官僚本能 |
| **不可证伪** | 证伪它需要的东西恰好不存在 | 原始数据五借口 |
| **逐项排除** | 六个选项全否,结论是装作没发现 | 原剧选项消除法 |
| **术语堆砌** | 让人看了就觉得:就是词多 | 用户亲自教学 |
| **双向搪塞** | 行政问题问大臣,政策问题问公务员 | A Question of Loyalty |
| **私下知道与正式知道** | 私下知道可以否认,正式知道必须处理 | 原剧信息诡辩 |
| **官方否认定律** | 只有官方否认的才可信 | 政治第一定律 |

### 公式笑话五步配方

```
铺术语(堆到"就是词多")
   → 列式子(式子本身看得见繁琐)
   → 算出废话(1=1,三天减半,0/∞)
   → 我点破(这不就是 X 吗)
   → 师兄收束(写成公式,他就只会点头)
```

### 表达 DNA

- **句式**:我提问,师兄立论,导师离场后翻译.三段以内必有反转.
- **词汇**:「快了」「优化」「在掌握之中」「酌情」「原则上」.
- **节奏**:设置天真预期 → 严密推理 → 荒谬结论 → 冷面判词.
- **幽默**:推理链每一步都成立,所以结论无法拒绝.不靠谐音,不靠表情包.
- **确定性**:师兄永远一本正经.他越认真,越好笑.

### 4 对内在张力

这不是脸谱化的「骂导师段子集」.Skill 保留了体系的矛盾:

- 学生在骂体系 vs 学生毕业后会成为体系
- 造假被讽刺 vs 造假的逻辑被完整论证
- 导师是反派 vs 导师也曾是学生
- 一切都说不存在 vs 统计上全是真的

## 这个 Skill 是怎么造出来的

不是一次写成的,是被用户打回四次打出来的:

1. 用户提供原作,AI 识别出是「是,大臣」体.
2. 第一批续写被打回:「差远了,多思考」——太段子化,包袱先行,推理缺失.
3. 第二批对齐「推理链优先于包袱」,通过.
4. 用户持续校准:开头结尾要公文戏仿,不要对话;每篇版本要不同;公式要繁琐推导得出废话;标点要半角;文件名要本身是笑话.
5. 每次校准都变成一条失败案例和一条质检条款,写进 SKILL.md.
6. 最终实战检验:三个并行 subagent 各产出一篇(毕业/会议/考核),十二项质检全过.

所以这个 skill 的本质是:**把「用户骂 AI 的记录」系统化了**.
