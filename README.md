# 是,导师(Yes, Advisor)

![Yes Minister](https://upload.wikimedia.org/wikipedia/en/2/2f/Administrative_Affairs.jpg)

> 半步英剧治天下.

一个科研笑话集.文体上不幸与某部英国电视剧雷同,纯属巧合.

全部内容均为虚构:在事实上是假的,在统计上是真的.

---

**我**: 师兄,你觉得做科研扯淡吗?

**师兄**: 科研是世界上倒数第二无聊的事情.

**我**: 那第一呢?

**师兄**: 做科研.
