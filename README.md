# 是，导师（Yes, Advisor）

> 本项目不存在。如你认为自己看到过本项目，请参照《结题报告》处理。

## 这是什么

一个科研笑话集。文体上不幸与某部英国电视剧雷同，纯属巧合。

全部内容均为虚构：在事实上是假的，在统计上是真的。

## 仓库结构

```
.
├── 正篇/                  # 笑话本体，共四辑
│   ├── 00-原作.txt        # 考古发现，抢救性发掘，一个字没敢动
│   ├── 01-长章.txt        # 论证严密，结论荒谬
│   ├── 02-短章.txt        # 两三句话，一刀毙命
│   └── 03-连台本戏.txt    # 四出长场景，包袱互相接应
├── 开题报告/              # 即"开头注释"。三个版本，任选一个
├── 结题报告/              # 即"免责声明"。三个版本，任选一个
├── LICENSE                # 《伦理审查批件》（MIT）
├── CHANGELOG.md           # 《整改台账》
└── CONTRIBUTING.md        # 《来稿须知》
```

## 如何组装

任选一个《开题报告》+ 任意正篇 + 任选一个《结题报告》，拼接即可。

本仓库不提供一键组装脚本。
组装工作历来由研究生手工完成——这是传统，也是培养方案的一部分。
